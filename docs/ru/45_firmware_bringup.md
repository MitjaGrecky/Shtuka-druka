# 45. Прошивка, первое включение и испытания (18.11.2026)

Роль «ПО и испытания»; решения за главным инженером (R186). Источники: 19, 21, 43, 44, README плат, `gen/design.py` P2, BQ25798 SLUSDV2C (регистры прочитаны). Расчёт; AS5600, TCA9546A по памяти.

## 1. Выводы и интерфейсы

| Плата | MCU | Занято | Свободно | Прошивка / отладка |
|---|---|---|---|---|
| P2 | RP2350A | GP0/1 I2C0; 2-7 сдвиговые регистры; 8 INT; 9 PM_ALERT; 10 LED; 16-19 SPI0 (ADC128); 20-22 MUX | **GP11-15, 23-29** | SWD 3 pin; BOOTSEL/USB «как на R2» (не нарисовано); USB в хаб R2 |
| R2 | RP2350A | 29 из 30: MIDI 0-5, TRS 6-11, MUTE 12, R2_OK 13, DAC SPI 14-17, клок 18-22, 74HC595 23-24, CV 26-29 | **GP25** | SWD, BOOTSEL (сторона B); I2C нет |
| M1 | нет | I2C 0x30, 0x37; 3×74HC165 | — | только через P2 (TCA 0x73 ch1) |
| A1 | XU316 ×2 | A: MCLK/BCLK/FSYNC, TDM, SPI tile 1, RST, XLINK, QSPI X0D01/04-07/10; B: PDM | — | **JTAG A и B, PH 6×2, 1,8 В, xTAG, распиновку проверить**; flash первый раз по JTAG (xflash, бит QE); PHY на tile 0 |
| PW | нет | TCA 0x70 (ch0/1 → BQ25798 0x6B ×2), INA226 0x40 | — | прошивки нет; жгут «Power telemetry» PH 8 к P2 |

**Конфликты и дыры (решает главный инженер):**
1. **Решено:** GP11 FAN_PWM (25 кГц, PWM5B), GP12 CHG_EN, GP13 FAN_TACH (счёт только на канале B = 6B), GP14 CHG_INT. В `design.py` P2 пока только SDA, SCL, ALERT: схемотехнику добавить разъём PH 8 и GPIO.
2. Решено (главный инженер): PWM и запрет заряда задаёт P2; в доке 43 поправлено. Жгут PW = PH 8 (SDA, SCL, ALERT, CHG_INT, FAN_PWM, FAN_TACH, GND, CHG_EN), пинов хватает.
3. **SDP, предложение (не принято в 19):** 0x25 TEMP_H5 (host → панель, °C×10); 0x17 POWER (панель → host: Pвх, T пакетов, ICHG, статус); 0x26 CHARGE_FAN (host → панель: разрешить заряд, лимит ICHG, режим вентилятора). Запрет заряда по температуре остаётся за панелью.
4. I2C: PW TCA 0x70 стоит за ch3 локального 0x73 (рядом Trill B 0x20, INA226), с декой P1 0x70 не конфликтует, пока ch3 не выведен на общую шину.
5. PREAMP_GAIN (19, 21): команда идёт в R2, а SPI к преобразователям у xcore A; связи R2 → A1 нет (передано схемотехнику).
6. BMS не опрашивается: BQ7791500 на пакете, к PW идут BAT, GND, NTC. Контроль заряда по BQ25798 (VBAT, IBAT, TS).
7. A1: страпы X0D04-06 = 000; пустой W25Q16 может не загрузиться до JTAG.

## 2. Что должна делать прошивка P2

| Требование | Реализация |
|---|---|
| Заряд только при 0…45 °C (43) | CHG_EN=1, лишь если: хост жив, T пакета 3…**42** °C, BUS норма. Выкл. при ≥ 43 °C, возврат ≤ 40 °C; ошибка опроса → 0; плюс EN_CHG (REG0F бит 5)=0. Аппаратные 44,4–45,7 °C (TS) и BM остаются |
| T пакета | TS_ADC (REG3F, 0,0977 % REGN/шаг): x = R/(R+9,31 кОм), R = 9,31·x/(1−x), B3435, R25 10 кОм (x = 0,345 ↔ 45 °C). ADC: REG2E бит 7; на батарее при VBAT > 3,2 В |
| BQ25798 | REG48 & 0x38 = 0x18. Сначала CELL=3S (REG0A), потом VREG 12,45 В (REG01), ICHG ≤ 3 А (REG03). WATCHDOG (REG10[2:0], по умолч. 40 с): 0 или WD_RST ≤ 10 с; по сбросу VREG → 12,6 В |
| Бюджет | INA226 и IBUS → ICHG и яркость LED: заряд = источник − система |
| Вентилятор | 25 кГц; f_H5: 50 °C → 25 %, 80 → 100 %; f_пак: 30 → 25 %, 42 → 100 %; PWM = max(f_H5, f_пак1, f_пак2). T_H5 нет > 2 с или пакет нет ≥ 5 с → 100 %. Тахо 0 при PWM > 20 % → ICHG=0 |
| Опрос | 0x73 ch3 → 0x70 ch0, ch1; 1 раз/с, CHG_INT внеочередно; потом закрыть каналы |
| Колесо AS5600 (44) | 0x36, RAW_ANGLE 12 бит, 170,7 отсчёта на щелчок (24/оборот). Шаг засчитан при 9° (60 %) от последней фиксации, фаза подтягивается, калибровки нет; опрос ≥ 1 кГц; STATUS MD/MH/ML → LOG |
| Старт | CHG_EN=0, FAN_PWM не драйвить (вентилятор на 100 %), LED минимум; watchdog RP2350 ≈ 1 с |

## 3. Первое включение (по порядку питания)

Нужны: лаб. блок 12 В с ограничением тока, мультиметры, осциллограф, термопара/ИК-камера, огнеупорный бокс. Li-ion только после шагов 1-6; зарядка без присмотра запрещена; PW и пакеты не заказывать до выполнения 43.

| № | Что | Измерить | Критерий |
|---|---|---|---|
| 1 | PW без пакетов: DC 12 В, ограничение 0,3 А, тумблер | EXT, BUS, 19, ±14, 15, 12, +5, +3V3 | ±5 %, ток холостой < 0,2 А |
| 2 | PW: адаптер 20 В и PD | VBUS, ток | PD 15-20 В, без срыва |
| 3 | I2C со стенда/P2 | 0x70, ch0/1 → 0x6B, 0x40, REG48 | 3 адреса, 0x18 |
| 4 | Заряд на **лаб. блоке 11,1 В** вместо пакета; NTC = декада | CE, TS, VREG | идёт при 10 кОм; стоп при 4,85 кОм; обрыв/КЗ NTC — стоп |
| 5 | CHG_EN 0/1, +3V3 выкл., обрыв провода | CE | любое из трёх = заряд выкл. |
| 6 | Вентилятор 0/25/50/100 % | обороты, 25 кГц | тахо сходится |
| 7 | Один пакет: заряд 0,2 А, термопара на средней ячейке | ячейки, T | баланс ≤ 20 мВ; **стоп 45 °C на нагреве феном** (эталон ±1 °C); BM 4,20 В |
| 8 | Пакет + PW: ICHG 1 А, потом 3 А | падение PCM 0,1-0,18 В, КПД, T | ≤ 3 А, T пакета < 40 °C, КПД ≥ 95 % |
| 9 | Два пакета + нагрузка, тумблер ≥ 15 А | ток шины, UVLO | старт > 10,1 В, стоп 9,3 В |
| 10 | R2: SWD, MUTE/R2_OK | GP12/13 при старте | заглушено до готовности; ключи разомкнуты при остановке R2 |
| 11 | P2: +5 В, SWD, I2C-скан, ADC128 | адреса по README, шум | все адреса, шум ≤ 3 LSB |
| 12 | M1, P1/P3/P4 по одному | энкодеры, LED | 8 энкодеров, кольца |
| 13 | A1 без аудио: JTAG A, затем B | 1,8 В, MCLK 24,576/22,5792 | xflash записан, USB виден |
| 14 | A1 + R1/F1, тихий старт 1-2 с | DC на выходах, щелчки | < 5 мВ, без щелчков |
| 15 | Колесо | STATUS MD=1, AGC | 24 щелчка/оборот, без пропусков на быстром вращении |

Немедленный стоп: T пакета > 45 °C, дым/запах, вздутие, ΔU ячеек > 50 мВ, плата > 80 °C.

## 4. Минимальный сценарий

1. Блок 12 В → PW → R2 + P2 по SWD. H5 не нужен: ПК с `tools/sdp.py` (R31).
2. P2: HELLO, HEARTBEAT, PAD ×64, ENCODER, LED_FRAME, колесо.
3. Пакет: заряд 1 А по CHG_EN при T < 42 °C, вентилятор по T пакета, телеметрия в LOG.
4. Зачёт: удар → звук ≤ 10 мс (19); потеря хоста → «нет связи» ≤ 0,5 с и CHG_EN=0.
