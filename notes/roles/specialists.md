# Дополнительные специалисты (ред. 18.11.2026)

Основные роли: главный инженер, дизайнер, аудитор. Остальные подключаются поручением на конкретную задачу, постоянные чаты не обязательны. Перед созданием проверь очередь и работающих исполнителей (дубли PW, F1 уже были).
Приоритет: механика корпуса и органов; затем по готовности входов схемотехника, встроенное ПО, производство. Редактор базы знаний нужен для сопровождения этого внедрения.

| Профиль | Когда | Результат |
|---|---|---|
| Инженер-конструктор | согласованы направление дизайна и основные размеры | сборка, крепёж, допуски, зазоры, кабели, обслуживание; первое поручение P2 (опоры пэдов, аккумуляторные отсеки) |
| Схемотехник / PCB | есть требования узла и интерфейсы | схема, детали, посадки, размещение, проверки заданной стадии; процент трассировки не критерий готовности |
| Встроенное ПО и испытания | до фиксации выводов и заказа плат | ресурсы MCU, протокол, минимальный стенд, программа первого включения; реальные измерения |
| Системное и звуковое ПО | определён минимальный музыкальный сценарий | воспроизводимый сценарий на вычислителе, задержка, нагрузка |
| Технолог и комплектование | выбор технологии и перед выпуском | проверенные BOM/CPL, монтаж, закупка; заказ и оплата только по поручению пользователя |
| Редактор базы знаний и навыков | миграция и пакеты изменений | индексы, указатели, версии навыков; смысл инженерного решения редакцией не меняет |

Общая форма поручения: цель, входная ревизия, область файлов, ограничения, зависимости, результат, проверка, предел вычислений, условие возврата ([../templates.md](../templates.md)). Смежный интерфейс молча не менять: запрос владельцу и продолжать независимую часть.
