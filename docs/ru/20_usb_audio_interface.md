# 20. USB-звуковая карта для внешнего компьютера (исследование, 31.10.2026)

Статус: **решено** — [R78](decisions/05_io.md) (карта в первой версии), R79–R84 (решения по USB-A, каналам, 48/96 кГц). Здесь — расчёты и источники.

## 1. Зачем

- R78: «с учётом железа, что мы впихиваем, не делать карту даже в первой версии — кощунство» (пользователь).
- Mini-ITX не умеет быть USB-устройством ([19](19_panel_protocol.md), раздел 9), поэтому порт «к компьютеру» даёт аудиоплата.

|---|---|---|

Вывод: схема «два USB на одной аудиоплате» проверена серийно.

## 3. Схема (R82)

| Узел | Функция |
|---|---|
| Аудиоплата | АЦП (≈ 14 входов + 2 запасных), ЦАП (Main, Aux, Cue), один тактовый генератор |
| USB-порт A (внутренний) | звуковая карта для вычислителя через внутренний хаб |
| USB-порт B (наружу, USB-C сзади) | звуковая карта и MIDI для внешнего компьютера |
| Маршрутизатор | цифровая шина TDM между портами, АЦП и ЦАП |

**Чип-кандидат: XMOS xcore.ai**, по одному на порт.
- Факт: эталонная прошивка UAC 2.0 и 1.0, High-Speed, до 384 кГц, асинхронный режим, MIDI и DFU; число каналов — параметры `NUM_USB_CHAN_IN/OUT` ([XMOS](https://www.xmos.com/documentation/XM-008854-UG/html/doc/rst/sw_usb_audio.html)).
- Факт: лицензия XMOS Public Licence v1; в коммерческих целях — только на чипах XMOS ([GitHub](https://github.com/xmos/sw_usb_audio)). Прошивка отдельная от кода проекта (AGPL, R20/R69). Вывод, не юридическая консультация.
- **Не проверено:** максимум каналов на чип при 96 кГц — проверить на отладочной плате.
- Запасной вариант: открытый микроконтроллер с High-Speed USB и TinyUSB (UAC2). Многоканальный режим там проверен хуже.

## 4. Тактирование

- Факт: в асинхронном UAC2 устройство задаёт темп, компьютер подстраивается по обратной связи; драйвер Windows поддерживает асинхронный режим с Windows 10 1703 ([Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/usb-2-0-audio-drivers)).
- Вывод: оба порта работают от одного генератора в асинхронном режиме. Пересчёт частоты внутри не нужен.

## 5. Каналы (R83, расчёт)

**Внешний компьютер видит карту 32 × 16:**
- 32 канала записи из Штуки: входы, дорожки (стемы), шины, Main — по матрице маршрутизации (например, 16 входов + 8 стерео-дорожек).
- 16 каналов воспроизведения в Штуку: каждая пара — источник дорожки «USB 1–2» и т. д.
- MIDI в обе стороны.

**Внутренний канал вычислитель ↔ аудиоплата:**

| Направление | Состав | Каналов |
|---|---|---|
| В вычислитель | 16 входов + 16 от внешнего компьютера | 32 |
| Из вычислителя | 6 на ЦАП (Main, Aux, Cue) + 32 в компьютер | 38 → 40 с запасом |

Пропускная способность: 40 × 48 000 × 32 бит = 61,4 Мбит/с в одну сторону (≈ 13 % от USB 2.0 High-Speed, 480 Мбит/с). При 96 кГц — 122,9 Мбит/с (≈ 26 %).

## 6. USB-A и SD (R79–R81)

- **Решено:** USB-A — только накопители и прошивка; звук и контроллеры на них не работают.
- **Сзади:** USB-A для постоянного накопителя (внешний SSD с библиотекой) и прошивки.
- **В блоке System у экрана:** второй USB-A и слот SD (R81), не на переднем торце.
- Оба USB-A — прямо к Mini-ITX, не через панель и аудиоплату: сбойная флешка не мешает звуку и ручкам.
- Порт в System — внутренний разъём USB 3 на плате и стандартный кабель (наличие разъёма у N100DC-ITX — проверить по руководству).
- USB-A и SD в общем углублении; рядом индикатор «идёт запись» — пока горит, не вынимать.
- Ограничитель тока порта — на плате.
- Проекты живут на внутреннем SSD (R57); звук не читает с флешки напрямую.
- Компьютер подключается по USB-C сзади (порт B). Внешние инструменты — по MIDI DIN и TRS.

## 7. 48 или 96 кГц (R84)

Один генератор на аудиоплате — частота одна на всё устройство.

| | 48 кГц | 96 кГц |
|---|---|---|
| Слышимый диапазон | до 24 кГц | до 48 кГц |
| Разница слышна | мета-анализ 18 опытов (> 400 слушателей): различие слабое, значимое; заметнее после тренировки ([JAES, Reiss 2016](https://www.aes.org/e-lib/browse.cfm?elib=18296)). Двойной слепой тест на музыке: значимых различий нет ([BAS](https://bostonaudiosociety.org/explanation.htm)) | |
| Нагрузка CPU | 1× | ≈ 2×: 16 дорожек на 1 ядре — 14 % против 31 % (замер облачной машины, `--rate 96000 --block 256`) |
| Дорожек на том же CPU | N | ≈ N / 2 |
| Буфер захвата 16 каналов × 60 с, 32 бит | 184 МБ | 369 МБ |
| Сэмплы на SSD | 1× | 2× |
| Внутренний USB, 40 каналов | 61,4 Мбит/с (13 %) | 122,9 Мбит/с (26 %) |
| Задержка при блоке 128 | 2,67 мс | 1,33 мс (нагрузка выше) |
| Октава вниз для сэмпла | верх обрезается на 12 кГц | верх до 24 кГц |
| Алиасинг в эффектах | решается передискретизацией 2–4× | меньше |

**Решено (R84):** закладываем 96 кГц в железо, работаем на 48 кГц, даём режим 96.
1. Железо сразу под 96 кГц (АЦП, ЦАП, XMOS, USB 26 %) — почти ничего не стоит.
2. По умолчанию 48 кГц: больше дорожек (R11).
3. 96 кГц — режим проекта, выбирается при создании; всё устройство переключается целиком; экран показывает, что дорожек примерно вдвое меньше. Для компьютера карта тоже на 96.
4. Захват «добычи звука» на 96 — тот же режим.
5. Замер M93 с прогоном 96 кГц — [18](18_benchmark_m93.md).

## 8. Ограничения

- **Windows:** встроенный драйвер в shared-режиме не поддерживает больше восьми каналов ([Microsoft](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/usb-2-0-audio-drivers)). Для 32 каналов в DAW нужен ASIO или монопольный режим. macOS и Linux — без драйверов (по классу UAC2; проверить).
- **Самая сложная плата:** два чипа XMOS и маршрутизатор. Сначала отладочная плата xcore.ai, потом своя разводка.
- **Земля:** порт B соединяет землю Штуки с компьютером; гул через USB-хаб монитора отмечен в [11](11_io_formats_research.md). Нужна развязка порта B (ADuM4166, [21](21_audio_board.md)) или отдельный путь земли — проверить на прототипе.
