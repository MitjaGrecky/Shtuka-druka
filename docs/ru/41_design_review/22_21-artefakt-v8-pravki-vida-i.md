## 21. Артефакт v8: правки вида и концепты К1–К3 параметрами генератора (17.11.2026)

С этого момента формы показывает только артефакт v8 из одной модели (`model3d/v8/build_v8.py`, `template.html`, главная сессия); эскизы руками больше не рисуем. Ниже — что дизайнер просит добавить.

### 21.1 Правки вида в `template.html` (режим «Снаружи» / «Корпус сплошной»)

| № | Правка | Зачем |
|---|---|---|
| В-1 | **Пэды — цветом из `layout_v7.json`** (строки: красный → розовый) с лёгким свечением (`emissive` ≈ 0,35 цвета, `roughness` 0,5); сейчас все пэды серые `plastic` | лицо инструмента — свет пэдов |
| В-2 | **Кольца огней ручек**: плоское кольцо Ø + 7 мм вокруг каждой ручки, цвет из раскладки (Param — фиолетовый, Level — цвет дорожки, FX / Filter — коралловый), `emissive` | без колец ручки выглядят как «болты» |
| В-3 | **Колпачки ручек и колесо** — матовый чёрный `#26292e`, `roughness` 0,8; на колесе верхний диск чуть светлее (`#3a3f46`), металлический ободок | материал вместо «серого ящика» |
| В-4 | **Кнопки** — тёмные `#3c4148`, цветная подсветка по полю `color` раскладки (Rec красный, Play зелёный, режимы — бирюзовый / фиолетовый) | читается группировка R89–R94 |
| В-5 | **Предложение дизайнера:** верх и бока — графит: `#2b2f35`, `metalness` 0,35, `roughness` 0,55, непрозрачный (1,0, а не 0,96: сейчас сквозь сплошной корпус видны платы) | анодированный алюминий (Д-8) |
| В-6 | **Предложение дизайнера — скругления**: обшивку в режиме «сплошной» строить не коробками, а `ExtrudeGeometry` профиля (y, z) по ширине 515 с `bevelSize` 4–5 мм, `bevelSegments` 3; фаска ступеньки 45° × 4 (оранжевая) | «Скругления не показаны» — главная причина, почему модель выглядит как ящик |
| В-7 | **Экран**: чёрное стекло и картинка-текстура (`CanvasTexture`: 8 столбцов клипов над столбцами пэдов, R107), `emissive`; вариант «антибликовая плёнка» — `roughness` 0,9 | экран — второе лицо |
| В-8 | **Индикаторы W2** — 14 сегментов зелёный / жёлтый / красный, светятся | |
| В-9 | **Гнёзда на переднем торце**: гайки (металлическое кольцо) и отверстие | видно, что спереди — гнёзда, а не щель |
| В-10 | **Ножки** 6–8 мм и мягкая тень под корпусом (`ShadowMaterial` на плоскости или тёмный эллипс) | корпус «стоит на столе», видна реальная высота |
| В-11 | **Свет**: `outputEncoding = sRGBEncoding`, `toneMapping = ACESFilmicToneMapping`, третий свет сзади-сверху (контровой) — кромки графита читаются | |
| В-12 | **Ортографическая камера для «Сбоку» и «Сверху»** (переключатель) | «на эскизах всё уплывает»: в перспективе сравнение силуэтов врёт |
| В-13 | Контур «было» — ещё и **полупрозрачной заливкой профиля** на виде «Сбоку» | сравнение одним взглядом |

### 21.2 Концепты К1–К3 как варианты 4–6 (параметры для `build_v8.py`)

Общее для всех трёх: без свеса; дека 30; аккумулятор под P2 (`130,300,60,160,3`); A1 на полу (`A1_Z0` 6, y 352–452 при глубине 500); PW x 245–345 на полу; гнёзда 6,35 под P1; **колесо y 268** (R173: посередине между Page / Back и началом ската); H5 на стойках 8 мм, x 391–511, y 361–481 (15 мм до задней стенки), порты вперёд, место под жгуты 45 мм перед ним; вентилятор 60 мм на задней стенке за H5 (x 421–481, z 6–66); **задние платы плоско**: R1 / R2 лёжа полосой вдоль задней стенки x 4–388, y 452–497, z 3–50, гнёзда горизонтально двумя рядами; блок «Питание / USB» в правом углу над вентилятором (z 70+). Новые параметры генератора, которые нужны: `REAR_BOARDS=flat`, `WHEEL_Y`, `W3_BELOW` (детали под W3 над H5: 0), `SCREEN_PLUGS=angled` (угловые штекеры HDMI / USB-C вместо изгибов кабеля), `POCKET=side`, `PROFILE` ломаной (для К3).
