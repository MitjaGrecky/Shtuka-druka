# M1: модуль 8 ручек экрана (ревизия 0.5)

| | |
|---|---|
| Размер | 224 × 34 мм, 4 слоя, 1,6 мм |
| Начало координат | задний левый угол контура; в файле KiCad контур сдвинут на (40, 40) мм |
| Отверстия M2 | 7 штук: углы (2,6; 2,6), (221,4; 2,6), (2,6; 31,4), (221,4; 31,4) и в задней полосе x = 56, 112, 168 (y 2,6): это решение P97, ждёт вашего «да» в записи, но отверстия уже на плате |
| Закреплено | 8 энкодеров (шаг 28 мм, ряд на 20 мм от заднего края), 96 огней (12 на кольцо, дуга 270°), 7 отверстий, разъём J1; дуги колец и веера у драйверов нарисованы и закреплены |
| Драйверы | 4 × LP5864 (U1, U6, U7, U8) в задней полосе, в зазорах 1, 3, 5, 7, снизу; каждый на 2 кольца |
| Снизу | драйверы, касание U2 (CY8CMBR3108), регистры U3–U5, подтяжки, разъём J1 (2 × 7) |
| Касание | под корпусами энкодеров нет меди на всех слоях (правила `under_encoder_*`) |
| Деталей | 163 |

**Что осталось развести:** катоды колец, линии SW, шина I²C, регистры, питание. Ориентир по трудности: Quilter и Freerouting оставляли у драйверов 4–12 неразведённых; у драйверов теперь по 8 выводов на сторону вместо 15.
Ручной порядок: сначала SW-строки (4 на драйвер), потом шина, потом регистры.
