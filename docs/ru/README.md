# Штука Дрюка: документы — карта

*Что где лежит и что из этого стоит читать. Решения — в [`decisions/`](decisions/README.md), они главнее любого документа. Обновлено 06.11.2026.*

**Статусы:** **рабочий** — по нему сейчас делаем; **справка** — исследование, из которого выросли решения, читать нужный раздел, когда возвращаемся к теме; **частично** — часть разделов заменена (указано, какие); **архив** — заменён целиком, лежит в архив.

Номера документов не меняются: на них ссылаются решения («13, раздел 3.5»).

**Большие документы разбиты на части** ради экономии контекста (18.11.2026, текст без потерь, проверка `tools/split_docs.py --verify`): 41, 38, 09, 13, 11, 23. Путь `NN_имя.md` теперь индекс со списком частей, сами части лежат в `NN_имя/`. Читать нужную часть по её номеру раздела; «13, раздел 3.5» = часть `13_enclosure_layout_research/` с заголовком 3.5. Проверка ссылок и достижимости: `python tools/check_docs.py`.

## Где ещё что лежит

- `hardware/<плата>/` — KiCad, генераторы `gen/*.py`, `QUILTER.md`, `UNROUTED`.
- `mockup/` — шаблоны 1:1 и скрипты раскладки `layout/`. `model3d/` — 3D-модель и `fit/` (проверка деталей в Blender).
- `notes/handoff.md` — активная очередь между облачной и локальной сессиями; история в `notes/handoff_archive/` (индекс там же).
- `notes/roles/` — уставы ролей (главный инженер, дизайнер, аудитор, специалисты); `notes/skills/` — каталог навыков; `notes/tasks/` — карточки задач, передача, споры; `notes/templates.md` — шаблоны записей; `notes/rollout_2026-11-18.md` — что и как внедрено.
- `audit/` — аудит (устав, находки, отчёты; ведёт аудитор).
