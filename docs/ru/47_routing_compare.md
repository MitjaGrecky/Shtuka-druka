# 47. Сравнение трассировщиков (пилот BM и F1, 19.11.2026)

Три способа на каждую плату: Quilter, Freerouting 1.9, нативный автороутер EasyEDA Pro. Исходные `.kicad_pcb` не тронуты, результаты лежат в `hardware/<плата>/routed/<роутер>/`. Платы не заказывались.

Условия: 2 слоя, правила проекта (`.kicad_pro`), без заливок (`--no-pour`), чтобы сравнивать именно дорожки. Нетрассированные связи считаются `tools/route_stats.py` (pcbnew), DRC: `kicad-cli pcb drc --severity-all`, по одному запуску. DRC-счётчик без шелкографии (silk_*) и lib_footprint_issues: они одинаковы у всех вариантов, это свойство платы, не трассировки.

## Состояние

- Freerouting: готово на обеих платах, `routed/freerouting/*.kicad_pcb`, `.ses`, `drc.json`. BM разведена полностью, у F1 осталась 1 связь.
- Quilter: скачан текущий кандидат, задания на момент скачивания ещё шли ("не завершено"): BM job 6afe87330116ca42a48442b4, кандидат 1.1; F1 job 6afe87f40116ca42a48442b7, кандидат 2. Файлы в `routed/quilter/`. Quilter оставил по 4 неразведённых связи и нарушения hole_clearance (отверстия к дорожкам, реальное ограничение JLCPCB), поэтому как есть плату брать нельзя. Слои Quilter переименовал, заливок нет. Настройки: JLCPCB 2-Layer 6/6 mil, на F1 зазор дифпар поднят до 0,16 мм, CSV не загружались.
- EasyEDA: нативный автороутер (все цепи, 45 градусов, completion first, старые дорожки удалены, Top и Bottom, без заливок, поэтому Copper Rebuild не нужен). Сначала пришлось поправить правило Via Size: при импорте из KiCad диаметр и отверстие в нём перепутаны ("Incorrect via size"), задали 0,61 / 0,305 мм. DRC EasyEDA: F1 без ошибок связности и зазоров, BM одна неразведённая связь OCDP (U1.17 - R6.1). Единственное замечание "Netlist Error" (схема и PCB не сверены) есть у обоих и не про трассировку. Сохранено через API (`save()` вернул true, GUI-сохранение не делал: ввод прерывался).
- Итог: по нетрассированным и DRC лучше всех EasyEDA на F1 (0 и 0) и Freerouting на BM (0 и 0). Переходов меньше всего у Freerouting (16 на BM, 52 на F1), по длине Quilter короче, но недоразведён и с нарушениями hole_clearance.
