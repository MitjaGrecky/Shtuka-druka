# Уставы ролей (ред. 18.11.2026)

Каждая сессия читает общий вход `CLAUDE.md`, затем **только свой** устав: сначала «Короткий блок», полный текст по необходимости. Один действующий устав на роль.

| Роль | Устав | Область правок |
|---|---|---|
| Главный инженер | [chief-engineer.md](chief-engineer.md) | всё инженерное: `hardware/`, `model3d/`, `docs/ru/` (кроме отведённого другим), `tools/`, очередь и интеграция |
| Дизайнер | [designer.md](designer.md) | документ 41 (`docs/ru/41_design_review.md` и части `docs/ru/41_design_review/`), `docs/ru/img/41_*`, строка карты; инженерное передаёт задачей |
| Аудитор | [auditor.md](auditor.md) | `audit/`, `tools/audit/`, навык `shtuka-druka-auditor`; чужое не правит |
| Специалисты | [specialists.md](specialists.md) | по поручению главного инженера |

Порядок передачи и споров, шаблоны: [../templates.md](../templates.md), [../tasks/README.md](../tasks/README.md).
Старые локальные памятки ролей заменены этими уставами; при расхождении действует этот файл, затем более поздний указ пользователя.
