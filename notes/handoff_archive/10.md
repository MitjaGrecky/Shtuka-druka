### 2026-11-12, ПК: импорт M1 и W1 в EasyEDA Pro 3.2.209, сверка цепей через API (только чтение)
Мост: `easyeda/easyeda-api-skill` (node, 127.0.0.1:49620) + расширение run-api-gateway 1.0.5 (Allow External Interaction, Show in Top Menu).
Цепи платы: выводы площадок через `pcb_PrimitiveComponent`. Цепи схемы: `sch_Netlist.getNetlist()` виснет (30 с),
поэтому собраны по геометрии (выводы + провода + флаги, одинаковые имена = одна цепь). Сравнение с `netlist.net` по наборам выводов, без имён.

| Плата | Детали | Плата EasyEDA: цепи (≥2 вывода) | Схема EasyEDA: цепи |
|---|---|---|---|
| M1 | 163 / 163 | 146 / 146 совпали, склеек нет | 143 / 146 (данные облака, .tel); GND + 3V3 + 5V склеены |
| W1 | 38 / 38 (H1–H6 без выводов) | 35 / 35 совпали, склеек нет | 32 / 35; GND (31) + 3V3 (20) + 5V (13) склеены в одну цепь из 64 выводов |

- **Где склейка:** только в СХЕМЕ, в обеих платах. Документ платы EasyEDA берёт цепи из `.kicad_pcb`, там всё верно.
- **Причина** (проверено на схеме M1 по координатам): дело не в символах `power:GND/+3V3/+5V`, они импортируются как отдельные флаги
  `power_GND`, `power_+3V3`, `power_+5V`. Склеивают три символа `PWR_FLAG`: все три стали флагами с одним именем `power_PWR_FLAG`,
  и каждый стоит в одной точке со своим флагом (+5V в (140,−340), +3V3 в (180,−340), GND в (220,−340)). Одно имя = одна цепь → три шины замкнуты.
- Риск: «Обновить плату из схемы» в EasyEDA перенесёт склейку и на плату. До исправления плату из схемы не обновлять.
- Предложение облаку (не решение): в архиве для EasyEDA не ставить `PWR_FLAG` (или убрать их при упаковке `tools/pack_for_routing.py`);
  символы питания можно оставить. После правки ПК может повторить ту же проверку за пару минут.
- В EasyEDA: создан проект W1_kicad7 (импорт по умолчанию, «Import Document»). В M1_kicad7 и W1_kicad7 ничего не менялось и не сохранялось.
  Ограничение: геометрический сборщик для схемы M1 не прогонялся (для M1 взяты цифры облака по .tel).
- Попутно: в мосте ошибка, `POST /eda-windows/select` роняет сервер (переменная `activeWindowId` не объявлена); окно надо передавать полем `windowId` в `/execute`.
  После открытия или смены проекта расширение видит старые вкладки: помогает API Gateway → Reconnect (или выключить и включить расширение).
