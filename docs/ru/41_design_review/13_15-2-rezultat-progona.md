**П-зад — переделка задней стенки, без которой ни один вариант не собирается [предположение: задано в скрипте, не на платах]:**
1. Нижнее плечо R2 укоротить: правый край x 427 → **388** (−39 мм).
2. Окно DIN (MIDI) R2 сейчас на x 359–427: правую часть (x 391–427) перенести левее 388 или выше z 60 (над H5). Это «сжать плату с разъёмами» по ширине на ≈ 30–40 мм.
3. Блок «Питание / USB» (LAN, USB-A, два USB-C, DC, выключатель) — гнёзда на гайках с кабелями (R141), переезжают **над H5**: x 451–510, z 60–112. Плат не трогает.
4. Вентилятор 60 × 60 × 15 — на задней стенке над H5 (x 391–451, z 58–118), выдув назад; вход воздуха слева (как R163, только выход не вбок, а назад).

**Ниже 131 мм зад [факт: прогон]:** при верхе R1 / R2 ≤ 100 мм (сейчас R1 104, R2 113) зад 121 мм даёт 2 мелких столкновения (3,6 и 1,9 мм: кабель питания экрана о PW, карман USB о H5), их, скорее всего, снимает сдвиг PW и кармана; зад 116 — 5 столкновений, 110 — 7. То есть **«сжать плату с разъёмами» по высоте до 100 мм = зад ≈ 121**; ниже упирается уже экран в задние платы.
