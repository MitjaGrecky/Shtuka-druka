# 47. Сравнение трассировщиков (пилот BM и F1, 19.11.2026)

Три способа на каждую плату: Quilter, Freerouting 1.9, нативный автороутер EasyEDA Pro. Исходные `.kicad_pcb` не тронуты, результаты лежат в `hardware/<плата>/routed/<роутер>/`. Платы не заказывались.

Условия: 2 слоя, правила проекта (`.kicad_pro`), без заливок (`--no-pour`), чтобы сравнивать именно дорожки. Нетрассированные связи считаются `tools/route_stats.py` (pcbnew), DRC: `kicad-cli pcb drc --severity-all`, по одному запуску. DRC-счётчик без шелкографии (silk_*) и lib_footprint_issues: они одинаковы у всех вариантов, это свойство платы, не трассировки.
