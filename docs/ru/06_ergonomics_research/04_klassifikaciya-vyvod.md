## Классификация (вывод)

| Класс | Элементы |
|---|---|
| Нужно (подтверждено несколькими источниками) | Экран + ряд из 8 энкодеров с кольцами; клик у навигационного энкодера; кнопки Undo, Save, Capture; захват всегда включённым буфером; looper; перформанс-эффекты на кнопках или сетке; ресэмплинг; отдельные громкости мониторов и наушников; velocity на пэдах; подписи параметров на экране |
| Полезно | Кроссфейдер и сцены; джог-колесо; 4–6 выделенных ручек «звука» (фильтр, резонанс, drive, delay, reverb); давление на пэдах; сенсорная полоса; браузер сэмплов с избранным; автосохранение |
| Спорно (мало подтверждений) | 16 ручек по строкам сетки; 4 фейдера; сенсорные энкодеры с жестами; встроенный аккумулятор |
| Лишнее для нас | Сетка 64+16 пэдов; сотни эффектов вместо десятка хороших; режимы, зависящие от неподписанных комбинаций кнопок; несколько экранов с разной логикой |
| Нет данных | Влияние числа ручек на скорость работы; реальная польза панорамы на каждую строку |
