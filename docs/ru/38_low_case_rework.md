## 6. Рекомендации

1. **Идти через «ступень».** Она даёт низкую деку, не трогая экран, скат, R1 / R2 и A1, которые сейчас в работе. «Клин» — второй шаг, когда будут замер H5 без радиатора и решение по горизонтальным гнёздам.
2. **Не разводить P1–P4 и M1 дальше, пока не приняты ограничения по высоте снизу** (П-1…П-3): иначе разводку придётся повторять. P2 сейчас `UNROUTED` — момент удобный.
3. **Аккумулятор:** для уровня Push — плоский литий-полимерный; если важнее простая замена и покупка элементов — 18650 и дека ≈ 35 мм. Третий путь — половинная ёмкость (4S1P 18650 всё равно 20 мм: высоту не уменьшает), поэтому выбор именно между типами элементов.
4. **Тепло H5** при переносе назад и в тонком корпусе — главный технический риск; проверять на образце до корпуса.
5. **Жёсткость деки:** при высоте 26–28 мм и ударах по пэдам дно должно быть металлическим, опоры P2 — частыми.
6. Доля воздуха ≤ 30 % у «ступени» достигается только с уплотнением зада (H5, PW, A1 в один ряд, задние гнёзда по реальным размерам); считать после М-1, не раньше.
