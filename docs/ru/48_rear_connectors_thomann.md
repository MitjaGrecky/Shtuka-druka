## 3. Сетка и зоны

Шаг сетки по CSV: mini 18, большие 22, XLR 32 мм; зоны глубины 26/42/60 мм (от главного инженера). Пересчёт глубины корпусов Neutrik D-серии за стенкой не сделан: на страницах Thomann размеров нет, нужны даташиты NE8FDP, NAUSB-W, NCJ6FI, NF2D, NC3FD (список ниже). Признаки по форме: корпус D-серии 26×31 мм фланцем не должен налезать на соседа с шагом 22 мм по короткой стороне (25 мм ≈ допуск) — **проверять по чертежу, не принимать на веру**; XLR шаг 32 мм хватает.
