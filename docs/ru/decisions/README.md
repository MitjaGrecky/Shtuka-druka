## Как пользоваться

1. Этот файл читать всегда: он короткий, здесь приоритеты и где что лежит.
2. Файл блока открывать, только если задача его касается. В каждом блоке сверху то, что ждёт ответа, потом «Действует», внизу «Заменено» (историю можно не читать).
3. Архив (`99_archive.md`): судьба старых предложений, закрытые вопросы, устаревшие документы. Нужен только для истории.

## Правила ведения

- В R — только то, что сказал пользователь, лучше с цитатой «…». Свои выводы — в P. «Наверное», «скорее» — R с пометкой «предварительно».
- Короткое «да», «окей», «принимаю» на прямой вопрос о P — перенос P в R; строка P уходит из блока, в архив дописывается «Pn — как Rm».
- Новое R, отменяющее старое: старую строку не править по смыслу, перенести в «Заменено» своего блока со стрелкой «→ Rm», в устаревший документ — пометку «> **Обновление ДД.ММ.ГГГГ:** …».
- Каждое решение — ровно в одном блоке. Если касается двух, кладём туда, где его будут искать при работе, а в другом блоке ничего не дублируем.
- После изменения: обновить строку блока в таблице выше, приоритеты и «Где мы сейчас».
