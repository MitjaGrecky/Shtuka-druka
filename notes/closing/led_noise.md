# LP5864 и слышимый шум (R199), схемотехник, 26.11.2026

Источники: `notes/datasheets_text/ti_lp5864.md` (SNVSC52A), TI SNVU786 «LP5860 Register Maps» (поля Dev_initial, [ссылка](https://ti.com/lit/pdf/snvu786), прочитано поиском), `ti_lm70660.md`, `gen/design.py` плат. Расчёты частот — по формулам (1), (2) даташита; на железе не измерялось.

## Вердикт

- **VSYNC на GND оставить.** Он нужен только в режимах 2 и 3 (обновление кадром). Берём режим 1 (обновление по мере записи). VSYNC шум не убирает: внутренний генератор PWM он не синхронизирует. Схемы по шуму менять не нужно.
- **Шум решается прошивкой, и это обязательно:** со значениями после сброса драйвер работает неправильно.
- Единственная найденная ошибка схемы не про шум: питание огней P2, уже исправлена (rev 0.10).

## Прошивка (все платы с LP5864)

Dev_initial (001h) = **0x20**: Max_Line_Num = 4, Data_Ref_Mode = 00 (режим 1), PWM_Fre = 0 (125 кГц). После сброса там 0x5E:

| Поле после сброса 0x5E | Чем плохо |
|---|---|
| Max_Line_Num = 11 | 11 × 8,5…9,25 мкс = 94…102 мкс → **9,8…10,7 кГц, слышно**. Ограничивает ли LP5864 это значение до 4 сам, в даташите не сказано |
| Data_Ref_Mode = 3 | ждёт VSYNC; при VSYNC на GND кадр не выводится |

| Настройка при 4 строках | Период кадра строк | Частота |
|---|---|---|
| 125 кГц, SW_BLK 0,5 или 1 мкс, со сдвигом фаз или без | 34…37 мкс | 27,0…29,4 кГц, не слышно |
| 62,5 кГц | 66…69 мкс | 14,5…15,2 кГц, **запрещено** |

Все драйверы изделия используют 4 строки SW, поэтому число одно для всех. Исключение: тестовая плата пэдов (`hardware/pt-padtest`) с 3 строками: Max_Line_Num = 3 (Dev_initial = 0x18), ≈ 36…39 кГц.

- Dev_config1 (002h): **PWM_Phase_Shift = 1** (бит 1). По даташиту это снижает пульсации входного тока и писк керамики. После сброса выключен.
- Анимации: каждое обновление яркости меняет ток шины 5 В с частотой кадра (звуковой диапазон). Менять яркость плавными шагами, не переключать все платы одним скачком, держать общий лимит тока (док. 10).
- Режим 3 (16 бит) не использовать: младшие разряды раскладываются по многим циклам и дают низкочастотные составляющие (оценка, E3).

## Остаточные риски (проверить на первом образце)

1. **Керамика 4,7 мкФ 0805:** на 28 кГц не слышна; огибающая от анимаций может давать слабый звук. Менять детали только по результату прослушивания (E3).
2. **Биения между драйверами:** генераторы ±2 %, разностные частоты до ≈ 1 кГц. Слышны только при нелинейном смешении; VSYNC это не лечит (E3).
3. **PW, DRSS у LM70660:** частота модуляции расширения спектра по даташиту **10 кГц**, то есть в звуковой полосе. Если на образце слышен или виден тон 10 кГц: резистор CONFIG 41,2 к → 29,4 к (DRSS выключен, посадка та же). Это отмена части P125, решает главный инженер.
4. **Прослушивание:** всё белым, анимация 30–120 Гц, спектр на выходах A1 (док. аудита Q3, п. 5).
