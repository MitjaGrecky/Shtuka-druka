# P2 — Grid deck (main panel board)

Rev 0.1 (14.11.2026, PC): **schematic only** (391 parts, 262 nets). Generated by `gen/design.py` + `gen/make_sch.py`
(`KICAD_SYMBOL_DIR=<repo>/hardware/common/sym7`). No PCB yet: electrodes of the 64 FSR pads are placeholders (2-pad test points).

## What is on the board
| Block | Parts | Notes |
|---|---|---|
| Panel controller | RP2350A, W25Q128, 12 MHz, AP2112K-3.3 | copy of the R2 block; USB to the R2 hub (PH4), SWD |
| 64 FSR pads | 8 × 74HC4051 + ADC128S102 (V17) | row = ADC channel, S0–S2 shared; 10 k pull-down per pad, 1 k + 1 nF anti-alias per row; analog 3.3 V through a ferrite |
| 109 RGB LEDs | 5 × LP5864 (A–D 24 each, E 13) | 20 button + 64 pad + 25 strip; on TCA9546A 0x73 channels 0 and 2 |
| Buttons | 8 scenes + 2 arrows on 2 × 74HC165 | chained into the M1 module bus |
| Buses | M1 (2×7), P1/P3/P4 (2×8), Trill Bar A/B (PH4), PW monitor (PH4) | pull-ups for the main I²C bus are here only |
| Power | Micro-Fit 2×3 «+5V panel» from PW | all decks and modules are fed from here |

GPIO: GP0/1 I²C, GP2 ~SR_LOAD, GP3 SR_CLK, GP4–7 SR_P1/P3/P4/P2, GP8 ~INT, GP9 PM_ALERT, GP10 status LED,
GP16–19 SPI0 to the ADC, GP20–22 mux address.
