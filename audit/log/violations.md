## Правила учёта

1. Находка сначала получает номер, потом идёт агенту через замечание ([notices](../notices/README.md)).
2. Закрывается только по ответу трёх видов: исправлено / обосновано источником / решено пользователем.
3. Повтор того же типа у той же ветки: степень +1, запись ссылается на предыдущую.
4. Отчёты по датам — в [reports](../reports/); итог в журнал переносится одной строкой. Аудит №1: [2026-11-17_audit_1.md](../reports/2026-11-17_audit_1.md). Аудит №2: [2026-11-18_audit_2.md](../reports/2026-11-18_audit_2.md).
