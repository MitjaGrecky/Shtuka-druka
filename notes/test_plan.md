# План испытаний (19.11.2026)

Ревизии: PW 1.1, BM 0.3, A1 0.7, R1 1.0, R2 1.2, P2 0.7, U1 (USB-C PD). Порядок, критерии, безопасность Li-ion: `docs/ru/45_firmware_bringup.md`, раздел 3. Здесь только что чем проверять.

## Без прошивки (мультиметр, осциллограф, лаб. блок)

| Узел | Проверка | Прибор |
|---|---|---|
| PW | шины EXT, BUS, 19 В, ±14, ±12, 15, 12, +5, +5_PANEL, +3V3 ±5 %; холостой ток < 0,2 А | блок 12 В с ограничением, мультиметр |
| PW | UVLO LM5176: старт 10,1 В, стоп 9,3 В | регулируемый блок |
| PW | заряд BQ25798 на блоке 11,1 В вместо пакета; стоп по TS при 4,85 кОм (45 °C) | блок, магазин сопротивлений |
| PW | CE: CHG_EN, +3V3, обрыв провода = заряд выкл. | мультиметр |
| PW | вентилятор: 25 кГц PWM от генератора/блока 3,3 В, без PWM = 100 % | осциллограф |
| U1 + PW | PD 15–20 В, VBUS на PW J2, без адаптера нет питания | PD-адаптер, мультиметр |
| BM 0.3 | NTC 10 кОм, прозвонка, питание от блока вместо ячеек: OV 4,200 В, UV 2,9 В, NTC 45 °C | блок, магазин, мультиметр |
| Пакет | U ячеек, разброс ≤ 50 мВ, NTC, заряд 0,2 А, стоп 45 °C феном | мультиметр, термопара |
| R1 | прозвонка гнёзд, аналоговые тракты с генератором 1 кГц, усиления, Phono RIAA (аналог) | осциллограф, генератор |
| R1 | фантом: 0 В выкл., 48 В вкл. через 6,81 кОм — **вкл. только вручную с блока** | мультиметр |
| R2 | MIDI in/out токи, CV/Sync: уровни по схеме | мультиметр |

## Нужна прошивка

| Что | Зачем |
|---|---|
| P2: I2C-скан, ADC128 шум ≤ 3 LSB, SR 165, LED, AS5600 колесо | вся панель |
| P2 управляет CHG_EN, FAN_PWM, чтение TS/INA226/тахо (GP11–14) | заряд, защита по 42 °C и 100 % вентилятор при отказе |
| R2: MUTE, R2_OK, 74HC595 (PH48, PHONO, ATT), реле выхода без щелчков | тихий старт |
| R2: MIDI сквозной, TRS A/B, CV DAC80504, sync | задняя стенка |
| A1: JTAG xflash, TDM, SPI к ADC/DAC, USB-хаб, DC выходов < 5 мВ | звук |
| Фантом: включение по каналам, медленный разгон | R118 |
| Phono/Line реле, ATT1/ATT2 | R118, R1 1.0 |
| Вентилятор тахо при PWM > 20 %, ICHG бюджет по INA226 | PW |
| Сквозной сценарий: удар → звук ≤ 10 мс, потеря хоста → CHG_EN=0 ≤ 0,5 с | зачёт |

## Что не проверить без пакета
OCD (9,6–14,4 А) и КЗ (24 А) BM; нагрев BM (0,23 + 0,18 Вт при 6 А); КПД заряда; UN38.3 пакета; 45 °C отсечка на реальном образце — только после покупки образца пакета.
