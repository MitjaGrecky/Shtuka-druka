## 2. Шаг сетки и зоны глубины

Шаг CSV: mini 18, большие 22, XLR 32, зоны глубины 26/42/60 мм (от главного инженера; в 46 их нет). **Вырез D-серии 24×30 мм** (по главному инженеру; размер фланца Neutrik помню по памяти ≈ 26×31 мм, не сверено) **не помещается** при шаге 22 мм ни в одной ориентации: вдоль 22 мм мешает размер ≥ 24; поперёк 26 мм (шаг z) помещается только вплотную. Поэтому D-варианты годятся только на шаге 32 мм (XLR/combo) и где соседей нет (LAN, USB, USB-C, DIN: уточнить по их r и z в CSV: DIN идут с шагом 22 мм, значит **MIDI Socket D-вида по сетке v6.1 не встаёт плотно**, нужна проверка по чертежу). Мини-джеки 3,5 мм на шаге 18 мм D-фланец не годится: остаются 3,5 мм-гнёзда с резьбой Ø6 мм (SJ-3523 и т. п. — на Thomann не нашёл). Глубина за стенкой по каталогу Thomann не известна: нужны даташиты (список в файле). Ток: контакты NE8, NAUSB, USB-C — слаботочные сигнальные; для питания (DC, выключатель) Thomann не предлагает.
