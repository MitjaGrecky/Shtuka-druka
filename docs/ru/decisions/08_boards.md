# Решения: платы

Карта плат, микроконтроллеры, протокол, огни, модули M1–M5, платы задней стенки. Правила ведения — в [README](README.md). Заменённое — в [99_archive.md](99_archive.md).

## Ждёт «да» или «нет» (инженерные: решает главный инженер, R186)

| № | Предложение |
|---|---|
| P75 | Кто разводит платы: схемы, расчёты, BOM под JLCPCB и проверки делает Claude — схемы кодом в формате KiCad в репозитории, ERC/DRC и картинки плат автоматически на GitHub при каждом изменении. Простые платы (разъёмы, питание, панель, плата управления) Claude раскладывает скриптом (места органов — из `layout_v7.json`) и трассирует автороутером Freerouting, пользователь смотрит в б |
| P82 | W1 Levels подключается к P1 той же шиной 2 × 7, что модули энкодеров (R123), и сам оцифровывает громкости (ADS1115 по I²C) — вместо шлейфа 2 × 5 с аналоговыми линиями |
| P83 | Огни Clip 1 и Clip 2 — на модуле M5, а не на W1 |
| P84 | Кнопки P48: тактовая кнопка + прозрачный толкатель-колпачок + 2 RGB по бокам |
| P85 | W1 на 8,5 мм под обшивкой (модули энкодеров — 6,5 мм) |
| P101 | Кнопки дек и W3 светят двумя RGB (слева и справа от кнопки, как P84) → по 2 LP5864 на деку |
| P102 | Модули M3, M4, M5 без касания (касание только у M1 и M2) |
| P103 | M5: кольца по 11 огней + 2 огня Clip — всё на одном LP5864 (24 RGB) |
| P104 | Кроссфейдер оцифровывает сама P4 (ADS1115 0x48, как громкости на W1), колесо — AS5600 (0x36) на P4 |
| P105 | Карман USB-A + SD на W3 — розничный модуль-удлинитель с кардридером, к W3 электрически не подключён |
