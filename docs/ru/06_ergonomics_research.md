## 3. Итоги по темам

1. **Ручки против меню.** Главное — не число ручек, а чтобы часто нужное не пряталось. Меню и неподписанные комбинации раздражают. Ручки группировать по смыслу, подписывать на экране, частое — на кнопки.
2. **Энкодеры и потенциометры.** Для всего «страничного» — энкодеры с кольцами: потенциометр не показывает значение после смены страницы. Потенциометры — только для постоянного (мастер, мониторы, наушники, вход). Касание энкодера — только подсветка значения, не смена режима.
3. **Перформанс-эффекты — ядро концепции.** SP-404: шесть эффектов, Skip Back, looper. EP-133: 12 punch-in эффектов по силе нажатия. Octatrack: сцены и кроссфейдер. Достаточно небольшого числа хороших эффектов; «лучше меньше, но доведённых» — ключевой урок.
4. **Захват.** Нужен буфер, который пишет всегда; захват одной кнопкой; выбор источника отдельной кнопкой; ресэмплинг без остановки. Слабые места: EP-133 — две руки; Digitakt II — моно в стерео, нет выбора входа; Play+ — без входа; Push 3 — без предусилителя.
5. **Пэды.** Хвалят давление и положение (MPCe, Push 3 MPE). Ругают отсутствие velocity и слабую чувствительность. Вывод: сетка различает силу; давление (aftertouch) желательно.
6. **Фейдеры.** Отзывов о пользе четырёх фейдеров почти нет. Подтверждён один ползунок — кроссфейдер Octatrack. Вывод: черновые четыре фейдера не подтверждены; один кроссфейдер — подтверждён.
7. **Экран.** Волна упрощает нарезку (SP-404). Сенсор хорош для выбора, волны и браузера, но не для точной правки (Live III). Вывод: параметры в реальном времени — только руками.
8. **Механика.** Качество кнопок и пэдов — в бюджете; на прототипе брать готовые.
9. **Простота.** «Не лучший сэмплер, но всё делает достаточно хорошо» (SP-404). Автор Elektronauts: «больше опций = лучше — иллюзия».

## 4. Классификация (вывод)

| Класс | Элементы |
|---|---|
| Нужно (несколько источников) | экран + ряд из 8 энкодеров с кольцами; клик у навигации; Undo, Save, Capture; всегда включённый буфер; looper; перформанс-эффекты; ресэмплинг; отдельные громкости мониторов и наушников; velocity; подписи на экране |
| Полезно | кроссфейдер и сцены; джог; 4–6 ручек звука (фильтр, резонанс, drive, delay, reverb); давление на пэдах; сенсорная полоса; браузер с избранным; автосохранение |
| Спорно | 16 ручек по строкам сетки; 4 фейдера; жесты сенсорных энкодеров; встроенный аккумулятор |
| Лишнее | сетка 64+16 пэдов; сотни эффектов вместо десятка хороших; режимы по неподписанным комбинациям; несколько экранов с разной логикой |
| Нет данных | влияние числа ручек на скорость; польза панорамы на каждую строку |

## 5. Что это значит для импровизации «из всего вокруг»

1. Устройство слушает: микрофон, линия, фоно, гитара, внутренние осцилляторы и свой выход — выбор одной кнопкой.
2. Буфер пишет всегда: сыграл, понравилось, Capture — и это сэмпл или цикл.
3. Звук идёт в перформанс-слой: фильтр, delay, reverb, drive, статтеры; сцены с кроссфейдером для плавных переходов.
4. Секвенсор, пэды и сетка вторичны: они повторяют найденное, а не добывают звук.
