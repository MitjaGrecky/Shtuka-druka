### 1.2 Предложение: места фиксированные, содержимое назначаемое (вывод)

Это меняет предложение P2 из документа 08 («фиксированная цепочка»). Фиксированными остаются только **места**, а что в них стоит, выбираешь ты.

**Дорожка (одинакова для всех источников):**

Источник → Фильтр → Слот 1 → Слот 2 → Посылы A, B, C, D → Уровень и панорама

- **Фильтр всегда первый** после источника, только тип назначаемый (ФНЧ, ФВЧ, полосовой, режекторный, формантный и т.д.). Фильтр — самое частое, что крутят руками (документы 06, 09), поэтому его место не меняется.
- **Слоты 1 и 2:** любой эффект из библиотеки, в том числе «Внешняя педаль» (документ 15, раздел 4).

**Шины посылов A–D:** в каждой 1–2 назначаемых слота. По умолчанию A — реверб, B — дилей, C и D пустые. Общие шины дешевле по процессору, чем реверб на каждой дорожке (документ 12, раздел 3).

**Мастер-шина:** 1–2 слота (например, компрессор и лимитер) плюс перформанс-эффекты по нажатию: повтор, остановка ленты, свип фильтра, понижение разрядности.

**Как это ложится на ручки:**
- 8 энкодеров под экраном — параметры выбранного блока (фильтр, слот 1, слот 2, шина).
- 6 макро-энкодеров по умолчанию: частота фильтра, резонанс, главный параметр слота 1, главный параметр слота 2, посыл A, посыл B. Назначение меняется, подписи видны на экране.
- В любом эффекте у каждого параметра есть «главный» флаг, поэтому макро-энкодеры знают, что крутить.

### 2.2 Какую лицензию взять нам (вывод)

- **Код устройства — AGPL-3.0.**
  - Тогда можно брать код Kick и JUCE под AGPL.
  - GPLv3 и AGPLv3 содержат согласованный раздел 13, который разрешает объединять код под этими двумя лицензиями ([Wikipedia](https://en.wikipedia.org/wiki/GNU_Affero_General_Public_License)). Значит, Surge XT, Dragonfly и Zynthian совместимы.
  - MIT, LGPL-3.0+ и GPLv2-or-later тоже совместимы.
- **Чего избегать:**
  - компоненты «только GPLv2» (без «or later»): по позиции FSF они несовместимы с GPLv3 (общеизвестно, проверять у каждого компонента);
  - закрытые движки (например, Pianoteq) — только как отдельные программы пользователя, не в нашей прошивке.
- **Сетевая оговорка AGPL:** если у устройства будет веб-интерфейс по Wi-Fi, пользователям сети нужно предлагать исходники. Для открытого проекта это просто ссылка на репозиторий.
- **Железо (схемы, платы, корпус) — CERN-OHL-S-2.0.** Строго взаимная лицензия для железа: кто выпускает изделие, обязан дать полные исходники, а изменённые версии остаются под той же лицензией ([choosealicense](https://choosealicense.com/licenses/cern-ohl-s-2.0/)). Если заимствуем аналоговые схемы Mutable Instruments, их лицензия CC BY-SA 3.0 требует указать авторство.
- **Kickstarter и открытость совместимы:** продавать устройство можно, исходники просто должны быть доступны.
