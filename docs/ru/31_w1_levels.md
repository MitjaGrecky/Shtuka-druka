# Штука Дрюка: плата W1 Levels (наклон слева)

*06.11.2026. Вторая плата по схеме P75 после M1: простая, разведена своими силами (Freerouting 1.9), без внешнего сервиса. **Факт** — из источника, **вывод** — моя логика, **решено** — решение пользователя. Основа: панель v7 (R107, документ 27), карта плат (R119, документ 29), шина модулей (R123, документ 30), громкости (R13, R87).*

## 0. Коротко

- **Что на плате:** 4 потенциометра громкости с упорами (Main, Cue Mix, Phones 1, Phones 2), 2 кнопки P48 с RGB-подсветкой, окно под модуль M5 (Gain 1 + 2). Микроконтроллера нет.
- **Размер:** 92 × 126 мм по наклону (x 10–102, s 12–138 мм от сгиба), **2 слоя**, детали с двух сторон: сверху — потенциометры, кнопки и огни; снизу — микросхемы, обвязка и оба разъёма.
- **Связь:** та же шина 2 × 7, 1,27 мм, что у модулей энкодеров (R123): J1 — к P1 через сгиб, J2 — к M5. Громкости оцифровывает сам W1 (АЦП по I²C), поэтому аналог по шлейфу не идёт (P82).
- **Проверка:** схема совпадает с данными (141 вывод, 0 расхождений), DRC — 0 ошибок, 0 неразведённых (локально KiCad 7; ERC и DRC KiCad 10 — в CI при пуше).

## 2. Схема

| Узел | Детали | Как работает |
|---|---|---|
| Громкости | 4 × RK09K → RC 1 кОм / 100 нФ → **ADS1115** (16 бит, I²C 0x48, C37593) | Концы потенциометра на GND и +3,3 В, движок — на вход АЦП. Положение ручки однозначно = громкость (R87) |
| Кнопки P48 | 2 × TS-1187A на землю, подтяжки 10 кОм (сборка C25725) → **74HC165** (C80696) | Регистр стоит в общей цепочке модулей: P1 читает W1 первым — D7 P48 1, D6 P48 2, D5–D0 = 1, потом регистры M5 |
| Подсветка P48 | **IS31FL3218** (18 каналов ШИМ, I²C 0x54, QFN-24, C2940546), 4 RGB | По 2 огня на кнопку (слева и справа под колпачком) — 12 каналов из 18. Ток 76,05 / R_EXT: с 4,7 кОм — 16 мА |
| Шина | J1 (к P1), J2 (к M5): 2 × 7, 1,27 мм (C3975190) | +5 В, +3,3 В, земля, I²C и INT проходят насквозь; цепочка регистров: M5 SR_OUT → DS регистра W1 (подтяжка, чтобы без M5 читались единицы), Q7 → SR_OUT к P1 |

**Факт (даташит IS31FL3218):** адрес фиксированный 1010 100 (0x54), питание 2,7–5,5 В, порог высокого уровня SDA/SCL/SDB 1,4 В, I_max = 76,05 / R_EXT мА (R_EXT в кОм), рекомендуемый минимум R_EXT 2 кОм; только запись ([даташит, Mouser](https://www.mouser.com/datasheet/2/198/IS31FL3218_DS-1949531.pdf)). **Вывод:** питаем от +5 В, шина I²C 3,3 В распознаётся.

**Адреса I²C на шине W1 + M5:** ADS1115 0x48, IS31FL3218 0x54, драйвер огней M5 IS31FL3741A 0x30 (как у M1) — пересечений нет.

## 3. Плата

| Параметр | Значение | Почему |
|---|---|---|
| Слои | 2 | Мало выводов; разводка сходится без внутренних слоёв |
| Дорожка / зазор | 0,15 / 0,15 мм; питание (+5 В, GND) 0,3 мм | Стандарт JLCPCB для 2 слоёв — от 0,127 мм; 0,4 мм не подходит к выводу QFN с шагом 0,5 мм, поэтому 0,3 |
| Переходные | 0,6 / 0,3 мм | Минимальное сверление JLCPCB на 2 слоях — 0,3 мм |
| Земля | Заливка GND с обеих сторон после трассировки, сшивка переходными | Экран для входов АЦП и общий возврат |
| Окно M5 | 83 × 35 мм (вырез в плате), по бокам перемычки по 4,5 мм | Модуль M5 стоит в своей плоскости, как M1 у P2; через перемычки идут питание, I²C и линии кнопок |
| Глубина | Верх платы на 8,5 мм ниже внутренней стороны обшивки | Корпус RK09K по рисунку Alps до 7,4 мм + 1 мм воздуха; модули энкодеров остаются на 6,5 мм |
| Закреплены | Потенциометры, кнопки, огни, разъёмы, отверстия | Их места задаёт панель |

**Трассировка:** Freerouting 1.9, 100 проходов, затем заливки и сшивка — скрипты M1 используются как библиотека (`hardware/w1-levels/gen/`).

## 4. Проверка в 3D

Плата с окном, потенциометры (высота 7,4 мм — оценка по рисунку Alps), выводы под платой, микросхемы, оба разъёма со штекерами шлейфа и модуль M5 в окне (оценка: плата 82 × 34 мм на 6,5 мм под обшивкой, два корпуса EC11E) добавлены в `model3d/fit/fit_model.py` прямо из `design.py` W1 — вместо прежней коробки-оценки.

**Результат:** 387 деталей во всём корпусе, **0 столкновений, 0 зазоров меньше 1 мм**. Под W1 стоит аудиоплата A1 — с ней тоже чисто. Корпуса энкодеров M5 касаются обшивки, как задумано (как у M1).

## 5. Предложения (ждут «да» или «нет»)

| № | Предложение | Почему |
|---|---|---|
| P82 | W1 подключается к P1 той же шиной 2 × 7, что модули энкодеров (R123), и сам оцифровывает громкости (ADS1115 по I²C) — вместо шлейфа 2 × 5 с 4 аналоговыми линиями из документа 29 | Тихий аналог не идёт по шлейфу рядом с ШИМ огней; один тип шлейфа во всём устройстве; P2 не тратит каналы АЦП |
| P83 | Огни Clip 1 и Clip 2 стоят на модуле M5, а не на W1 | По раскладке v7 они попадают в окно модуля (s 99 мм, рядом с Gain); драйверу M5 хватает каналов |
| P84 | Кнопки P48: тактовая кнопка на плате + толкатель-колпачок из прозрачного пластика + 2 RGB по бокам | Конструкция кнопок панели ещё не выбрана; это простой вариант для первой платы, его можно заменить |
| P85 | Плата W1 ниже под обшивкой (8,5 мм), чем модули энкодеров (6,5 мм) | Потенциометру RK09K нужна высота корпуса; энкодеры M5 остаются на своей высоте в окне |

## 6. Открытые вопросы

1. Точная высота корпуса RK09K и характеристика (нужна линейная B): суффиксы A6S / A5R / A8G в каталоге Alps не расшифрованы — сверить по даташиту или на образце.
2. Длина вала потенциометра под ручку над обшивкой (у RK09K 15–30 мм).
3. Колпачки кнопок P48 и материал световода (вместе с обшивкой).
4. Модуль M5: его размер (82 × 34 мм заложено в окно) и разъём — уточнить, когда будем его делать.

## 7. Результаты проверок

| Проверка | Результат |
|---|---|
| Схема ↔ данные (`gen/check_netlist.py`) | 141 вывод, 0 расхождений |
| DRC локально (KiCad 7) | 0 ошибок, 0 неразведённых; предупреждения: 34 «библиотека не подключена» (так же у M1), 5 о надписях шелкографии у обвязки драйвера |
| ERC и DRC KiCad 10 с проверкой соответствия схеме | в CI при каждом пуше (воркфлоу сам находит все проекты в `hardware/`) |
| 3D-посадка | 0 столкновений, 0 зазоров < 1 мм (раздел 4) |

**Урок трассировки (вывод):** силовые дорожки 0,4 мм не подходят к выводу QFN с шагом 0,5 мм — автотрассировщик оставлял питание и соседние линии неразведёнными; с 0,3 мм всё сошлось за один прогон. Обвязку драйвера поставил рядом, а не вплотную к сторонам корпуса, чтобы выводы свободно расходились.
