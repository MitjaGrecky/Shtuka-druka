# 37. Как сделать корпус ниже: варианты по высоте (анализ, 16.11.2026)

Статус: **только анализ и гипотезы**. Схемы, `hardware/*/gen/design.py` и решения не менялись. Где вариант требует пересмотра решения (R44 «спереди 68 мм, наклон 30°», P94, R109), так и написано. Расчёт — `model3d/fit/fit_model.py` (новые параметры по умолчанию ничего не меняют) и `model3d/fit/lower_case_study.py` (для каждого набора параметров ищет самую низкую переднюю высоту `FRONT_Z` без столкновений). Допуск модели ≈ 0,3 мм: «оболочки деталей снизу» — оценочные коробки, их касание до 0,3 мм модель прощает.

## 1. Из чего сейчас складывается 68 мм под пэдами

Стек по z в зоне платы P2 Grid (z = 0 — наружная сторона дна), `FRONT_Z = 68`:

| z, мм | Что | Толщина |
|---|---|---|
| 0–3 | обшивка дна | 3 |
| 3–6 | стойки H5 | 3 |
| 6–50 | ODROID-H5 с радиатором (плата 1,6 + 42,4 сверху) | 44 |
| 50–52,9 | **запас** между H5 и деталями P2 снизу | **2,9** |
| 52,9–56,9 | оценочный объём деталей под P2 | 4 |
| 56,9–58,5 | плата P2 | 1,6 |
| 58,5–65 | пространство под обшивкой: тела энкодеров (у P2 — слой FSR и кнопки) | 6,5 |
| 65–68 | верхняя обшивка | 3 |

Итого 3 + 3 + 44 + 2,9 + 4 + 1,6 + 6,5 + 3 = 68. Это единственное место в корпусе, где «под пэдами» что-то лежит; остальные платы панели (P1, P3, P4) пустые снизу, под ними просто воздух.

**Две поправки к прежним выводам (док. 35).**

1. **Колесо P4 не ограничивает высоту.** В модели корпус подшипника колеса стоял на абсолютной высоте z = 63,25 (под обшивкой 68 мм). Из-за этого «минимум 66,5 мм» в разделе 3а док. 35 — артефакт модели: пакет магнит + подшипник = 6,5 мм под обшивкой, ровно как у энкодеров, и опускается вместе с ней (параметр `WHEEL_TRACK=1`). Условие: расстояние P4 – обшивка остаётся 6,5 мм.
2. **Электролиты и разъёмы на нижней стороне P2 стоят в зоне H5.** Объём «детали снизу 4 мм» — оценка. По `p2-grid.kicad_pcb` на нижней стороне P2 есть два электролита CP 6,3 × 7,7 (C1, C2, высота 7,7 мм), ряд кабельных разъёмов JST-PH (J2, J3, J8, J9, J10) и штыревых 2 × 8 / 2 × 7 с шагом 1,27 мм (J4–J7), всё на плате по y 57–80 от дальнего края, x 56–153. В координатах корпуса это x ≈ 166–263, y ≈ 182–205, то есть **прямо над H5** (x 136–306, y 140–260), где запас 2,9 мм. Модель этого не видит (там ровная коробка 4 мм). Значит, при 68 мм H5 под P2 с текущей раскладкой P2 **уже не помещается**; платы переразмещать нужно в любом варианте с H5 под пэдами (вынести эти детали из квадрата H5 или оставить окно). Высоту штыревого разъёма с вилкой нужно проверить по даташиту (оценка ≈ 7–8 мм).

## 2. Лестница ограничителей (что упирается следующим)

Прогон «опускаем `FRONT_Z` шагом 0,25 мм, когда каждая пара деталей впервые сталкивается»; конфигурация: колесо едет с обшивкой, F1 лежит, R2 уже на 5 мм короче (иначе W2/R2 упирается на 0,25 мм раньше). Задняя высота при этом всегда `FRONT_Z + 75` (наклон 30°).

| Нижняя граница `FRONT_Z`, мм | Что упирается | Откуда |
|---|---|---|
| 65,1 | **детали под P2 ↔ H5** (при 4 мм оценке) | стек раздела 1 |
| 65,1 | плата наушников F1 (стоит вертикально, до z 50) ↔ детали под P1 | только если F1 вертикальная |
| 64,9 | W2 (детали снизу) ↔ R2, перекрытие по x на 4 мм | R2 доходит до x 359, W2 начинается с 355 |
| 62,75 | W2 и W3 (детали снизу) ↔ верх оболочки задних гнёзд (z 112) | оценка «всё, что торчит из задней стенки» |
| 61,25 | плата P2 ↔ H5 | плата без деталей, чистый стек |
| 60,75 | W1 ↔ верх оболочки задних гнёзд | то же |
| 59,5 | матрица экрана ↔ R2 (z до 113) | R2 высокая |
| 58,5 | платы W2, W3 ↔ задние гнёзда | |
| 57,5 | матрица ↔ задние гнёзда | |
| 54,75 | W1 ↔ R1 (z до 104) | |
| 54 | W3 ↔ аккумулятор (под ним z 3–48) | |
| 53 | верхняя обшивка ↔ H5 | потолок H5 сам |
| 51–49 | стекло и обшивка ската ↔ R2/R1/гнёзда, кабель питания экрана ↔ PW | |
| 48 | детали под P1 ↔ гнёзда наушников (z 17–33) | |

Читать так: **до ≈ 65 мм** высоту держат H5 под P2 и вертикальная F1; **с 65 до ≈ 59** — задняя стенка (гнёзда, R1, R2), которая упирается в скат; **ниже 54** — сам H5 и аккумулятор. Низ корпуса определяется не пэдами, а тем, что задняя стенка и скат стоят вплотную друг к другу и скат опускается вместе с передом.

## 3. Варианты

Выигрыш — от 68 мм, расчёт `lower_case_study.py`. «Дальше упирается» — что идёт следующим после этого варианта.

### 3.1. Дешёвое (не трогает решения)

| № | Вариант | Нижний `FRONT_Z` | Выигрыш | Цена | Дальше упирается |
|---|---|---|---|---|---|
| A | Колесо едет с обшивкой (артефакт, раздел 1) | 65,1 | 2,9 мм | ничего, просто честная модель | F1, H5/P2 |
| B | F1 горизонтально под гнёздами (P94, уже предложение) | 65,1 (один не даёт) | 0, но снимает F1 до 48 мм | F1 — одна плата, она ещё не сделана | H5/P2 |
| C | R2 короче на 5 мм по x (или W2 на 5 мм вправо) | −0,25 | 0,25 | R2 идёт в работу у другой сессии; W2 вправо меняет панель v7 | H5/P2 |

То есть без трогания H5 и задней стенки корпус держит **≈ 65 мм** (минус 3 мм).

### 3.2. Что делать с H5 под P2

Каждая строка добавлена к варианту A+B+C; результат упирается в стенку 62,75 (задние гнёзда над W2/W3), поэтому одиночные приёмы выглядят одинаково — разница в цене.

| № | Вариант | Нижний `FRONT_Z` | Выигрыш | Цена | Риск |
|---|---|---|---|---|---|
| D | Окно в P2: детали и разъёмы снизу выведены из квадрата H5 (объём 4 → 0 мм над H5) | 62,75 | 5,25 | перекладка P2 (раздел 1: электролиты, ряды разъёмов, к тому же они нужны по кабелям PW/R2) | разъёмы переезжают на край платы, кабели длиннее |
| E | Слой над P2 тоньше: 6,5 → 4,5 мм только у P2 (P2 ближе к обшивке) | 63,0 | 5,0 | FSR-слой + кнопки + Trill Bar в 4,5 мм; M1 остаётся на 6,5 (шина кабелем) | тач-полосы Trill Bar и кнопки сцен; P2 на другой высоте, чем M1 |
| E2 | то же, 3,5 мм | 62,75 | 5,25 | | запас на FSR-стек и ход кнопок нужно проверить макетом |
| F | H5 без стоек (на самом дне) | 62,75 | 5,25 | плата ложится на дно, **M.2 снизу и ножки не помещаются** | риск: M.2 на обратной стороне (док. 35), тепло через дно |
| G | Радиатор H5 ниже: 44 → 35 мм (гипотеза) | 62,75 | 5,25 | другой радиатор или пластина-теплораспределитель на дно; **44 мм у производителя не расписано, высоту без радиатора измерить** | перегрев N300 в закрытом корпусе без вентилятора |
| H | **H5 переезжает назад** (`COMPUTER=H5REAR`), аккумулятор плоский (8 элементов в ряд 155 × 75 × 25 вместо 90 × 80 × 45) под сетку | 62,75 | 5,25 | см. раздел 4, R109: решает пользователь | сзади H5 впритык к R2 (0,4 мм), тепло хуже |
| H0 | H5 сзади, аккумулятор **прежний** (45 мм) под сеткой | 63,0 | 5,0 | аккумулятор встаёт на место H5 и держит те же 48 мм | не выигрыш от аккумулятора — потолок 63 |

Вывод: все пути к 62,75 стоят примерно одинаково по результату, но разной ценой для P2. Самый дешёвый по железу — D (перекладка P2 без изменения толщины пространства над платой), самый «чистый» по эргономике. Хуже всего F (теряем M.2, тепло).

### 3.3. Задняя стенка и скат (после 62,75)

| J | + все гнёзда до 90 мм, R1 до 95, R2 до 100 (R2 меньше на 13 мм по высоте) | 56,0 (H5 сзади), 55,25 (H5 под P2 с вариантами D+F) | 12–12,75 | R1 и R2 перекомпоновать, DIN и 6,35-мм гнёзда на одну линию ниже | все задние платы перегенерировать; решения по R120 остаются |

### 3.5. H5 под экраном (по центру ската), под пэды уходят A1 / аккумулятор / PW (вопрос пользователя, 16.11.2026)

Что лежит под экраном сзади: A1 (x 20–240), PW (300–400), аккумулятор справа (414–504); изгибы кабелей экрана EP — **x 292–327, y 343–407, от z 42 вверх**, плата драйвера экрана — x 175–262, y 342–397, от z 77. Значит, H5 (44 мм, верх z 50) не может стоять под изгибами кабелей (x 292–327): при 68 мм столкновение 7,5 мм. Свободно место **левее**: x 170–290. Чтобы туда поставить H5, A1 уходит под сетку P2 (x 20–240, y 190–290; плата 22 мм высотой, под P2 места хватает до `FRONT_Z` ≈ 43), PW сдвигается вправо (x 300–400), аккумулятор — плоский, 25 мм, под сетку. Платы под пэдами A1 и аккумулятор **высоту не задают** (верх z 28 против низа деталей P2 на T − 15,1).

Прогон (`H5_REAR_X=230, PW_X0=300, A1_Y0=190, BATT_FLAT=1`): нижняя передняя высота **62,75** (задние гнёзда над W2/W3 — та же стена, что у H5 справа); с гнёздами справа ≤ 100 мм — **62,25**, дальше упирается плата M1 (y 263–297): H5 лежит на 4 мм ниже её края, детали M1 снизу (U4) задевают H5 при 62,25. Глубины между сгибом и R1 (y 297,5–413) — 116 мм, H5 120 мм, так что отодвинуть H5 от M1 нельзя; вариант — перенести U4 или сдвинуть M1 вперёд на 4 мм. Дальше, по аналогии с H5 справа, ожидается ≈ 56 мм при всех задних платах ниже (J), **эту комбинацию целиком не прогонял**.

Итог: перенос H5 под экран даёт **то же, что перенос H5 назад вправо** (≈ 62,5 мм), но стоит дороже: A1 теряет прямую стыковку с R1 (кабель вместо платы под прямым углом, R120), добавляется место под A1 под сеткой, а H5 лежит под M1/экраном рядом с платой драйвера. Преимущество: H5 в середине, а справа остаётся место под аккумулятор и PW. Решения, которые затрагиваются: R120 (A1 стыкуется к R1), R109 (отсек аккумулятора справа).

## 5. Лучшая комбинация

**Рекомендация (в порядке цены) — «средняя»:** A + B + D + задние гнёзда справа (I). По модели **≈ 61,25 мм спереди (−6,75 мм)**, задняя высота ≈ 136 мм; дальше упирается сама плата P2 в H5 (чистый стек 3 + 3 + 44 + 1,6 + 6,5 + 3). Если макет покажет, что над P2 хватает 4,5 мм (E), получается **60,75** (дальше W1 и задние гнёзда слева). Что для этого надо:

1. P94 — F1 горизонтально (сейчас только предложение);
2. P2 перекладывается так, чтобы под H5 (x 136–306, y 140–260) на нижней стороне не было электролитов и разъёмов — и вообще нет «4 мм деталей» (резисторы 0402 и микросхемы можно оставить: 1,2 мм, запас 2,9 мм это допускает; **электролитов 7,7 мм и разъёмов в квадрате H5 быть не должно**);
3. R2: гнёзда справа от x 340 не выше z ≈ 100, и R2 на 5 мм короче по x (или W2 сдвинуть);
4. решения R44 / R109 не меняются: высота спереди 68 → ≈ 61 — это уточнение R44, не его отмена.

**Если нужно ещё ниже (≈ 55):** добавить J (все задние гнёзда ≤ 90, R1 ≤ 95, R2 ≤ 100, H5 сзади или без стоек) — это уже переделка R1/R2/A1. Либо L (наклон 33–34° при 143 мм сзади, без правок R1/R2) — тогда решает пользователь.

**Что я бы не делал:** H5 без стоек (F — теряем M.2 и тепло), короткий радиатор без замера теплового режима (G, K), и H5 сзади ради высоты (H): выигрыш такой же, как у D, а цена — тепло и R109.

## 6. Что не проверено

- Высота H5 без радиатора и реальный размер радиатора (44 мм «над ножками» — худший случай, док. 35).
- Высота штыревых разъёмов 2 × 8 с шагом 1,27 мм вместе с вилкой IDC (оценка 7–8 мм) и слой P2 сверху (FSR-лист, кнопки, Trill Bar). Параметры модели: `P2_PARTS`, `P2_GAP`.
- Что именно торчит из задней стенки выше 100 мм (оболочка гнёзд 112 мм — консервативная оценка по R2 с DIN-окном).
- Скат круче 30°: экран, окно в обшивке и панель v7 не пересчитаны (модель показывает только столкновения коробок).
