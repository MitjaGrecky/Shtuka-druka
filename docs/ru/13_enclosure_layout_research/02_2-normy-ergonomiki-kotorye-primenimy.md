## 2. Нормы эргономики, которые применимы

Из FAA Human Factors Design Standard ([гл. 6](https://hf.tc.faa.gov/hfds/download-hfds/hfds_pdfs/Ch6_Controls_and_visual_indicators.pdf), [гл. 9](https://hf.tc.faa.gov/hfds/download-hfds/hfds_pdfs/Ch9_Input_devices.pdf)):

| Норма | Значение | Как применяем |
|---|---|---|
| Наклон клавиатуры (9.1.11) | 0–25°, лучше меньше 15° | Основная панель 5–10° к пользователю |
| Шаг клавиш (9.1.8–9.1.9) | 18–19 мм по горизонтали, 18–21 мм по вертикали | Шаг кнопок не меньше 19 мм |
| Усилие клавиш (9.1.10) | 0,25–1,5 Н, лучше 0,5–0,6 Н | Подбор переключателей |
| Сенсорные зоны (9.4.2.4) | 19–38 мм, промежуток 3–6 мм; отклик ≤ 0,25 с | Колонки экрана 27 мм |
| Направление (6.1.1.2.1) | По часовой — увеличение | Все энкодеры и потенциометры |
| Кодирование размером (6.1.1.4.6) | Разница диаметров ≥ 13 мм | Навигационное колесо заметно крупнее |
| Работа вслепую (6.1.1.5.3) | Разная форма или ≥ 125 мм | Громкости — отдельной формы, у края |
| Важные индикаторы (6.2.2.1.8) | В пределах 15° от линии взгляда | Rec, перегруз, фантом — рядом с экраном |
| Мигание (6.2.2.1.29) | 3–5 Гц, только для срочного | Прошивка |

Практика:
- Для ручек около 25 мм между центрами — минимум, при котором ещё можно работать ([Ableton forum](https://forum.ableton.com/viewtopic.php?p=1306090)).
- Подставку под запястья у MPC Sample хвалят ([MusicRadar](https://www.musicradar.com/music-tech/samplers/the-closest-thing-akai-has-released-to-a-vintage-mpc-in-decades-akai-mpc-sample-review)).
- Устройства, лежащие плашмя, связывают с болью в спине ([Elektronauts](https://www.elektronauts.com/t/elektron-ergonomics/36812)).
